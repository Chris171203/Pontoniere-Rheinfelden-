# Store-Grafiken

Für den finalen Eintrag werden benötigt:

- App-Icon: 512×512 PNG
- Feature-Grafik: 1024×500 PNG/JPG
- mindestens zwei Smartphone-Screenshots ohne persönliche Statusleisteninhalte oder Mitgliedsdaten

Das aktuell in der App vorhandene Vereinslogo ist nur 96×96 Pixel groß. Es darf nicht einfach als finaler Store-Upload hochskaliert werden; benötigt wird das Original in hoher Auflösung oder als Vektordatei.
